# Product Validation Dashboard

Board-review dashboard for a 5-product Meta ads demand-validation test (30 days each).
Computes CTR, lead-conversion, reservation-conversion, CPL, CPR, CPM, and pessimistic/realistic/optimistic
eROAS per product against a 200% realistic-eROAS pass bar, plus per-product funnel-leak insights.

Single static file, no build step. Open `index.html` directly, or serve it with any static host.
